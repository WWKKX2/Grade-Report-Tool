# Grade Report Tool · 高中生个人成绩报告工具

> 单机本地运行 · 零外部依赖 · 双击 HTML 即可使用 · 数据只存在本机

一个面向新高一 / 高二 / 高三学生的成绩记录与分析小工具。支持「3+1+2」新高考选科组合，六科成绩录入、雷达图、趋势折线、单科/总分统计、院校层次参考（可自定义）。

**技术形态**：单个 `.html` 文件（约 3245 行 / 147 KB，HTML + CSS + JS 全内联）。双击即用，Chrome / Edge / Firefox 均可。无 CDN、无 `fetch`、无 ES Module、无需服务器、无需构建。

---

## ✨ 功能速览

- **六科成绩录入**（语文 / 数学 / 外语 / 首选二选一 / 再选四选二）
- **概览**：总分平均、最近完整考试总分、院校层次参考、六科平均横向条形
- **成绩**：按考试 / 按科目双视角
- **图表**：自研 Canvas 雷达图（得分率归一）+ 趋势折线（缺考自动断线，绝不补 0）
- **统计**：单科平均（含不完整考试的已录科目）、总分平均（仅完整考试）
- **设置**：选科组合、自定义满分、院校层次区间编辑器、导出 / 导入 / 清空
- **深色模式**：跟随系统 + 手动切换
- **响应式**：桌面 / 平板 / 手机

## 📦 安装与使用

**无需安装**。

```
1. 打开 index.html（双击即可，Chrome / Edge / Firefox 均可）
2. 到「设置」把选科改成自己的组合，按本省情况调整院校层次区间
3. 到「录入」添加考试（名称、日期、感受、班排 / 年排、六科分数）
4. 到「概览 / 成绩 / 图表 / 统计」查看分析
```

数据存在浏览器 `localStorage`（键名 `hs-grade-report-v1`）。同一台电脑、同一个浏览器、同一个文件路径下打开，数据就还在。

> 用隐私模式打开或浏览器禁用了本地存储时，页面顶部会出现橙色警告条——此时数据只在内存里，请及时到「设置 → 导出备份 JSON」保存。

## 🧪 测试（可选）

仓库里附带两个开发期验证脚本，需要本机装 Node.js ≥ 14：

```bash
npm install          # 无依赖，只为拿到 scripts
npm run check        # 语法校验 + 统计内核 54 项断言 + DOM id 交叉核对 + 示例数据校验
npm run smoke        # 用轻量 DOM 桩把整个应用跑起来，走完全流程
npm test             # 两个都跑
```

测试通过情况见 [docs/DESIGN.md](docs/DESIGN.md#9-验证记录)。

## 🔒 隐私

- 数据不出本机，不联网、不上传、不发请求
- 使用 `localStorage`，可通过「设置 → 导出备份 JSON」导出为独立 JSON 文件
- 清空操作需二次确认，且建议先导出备份
