# 高中生个人成绩报告工具 — 设计文档

> 单机本地运行 · 零外部依赖 · 双击 HTML 即可使用

**术语说明**：标题里的"3+2+1"按需求正文描述实现，即 **3+1+2**：语文、数学、外语必考；物理/历史二选一（首选）；化学/生物/政治/地理四选二（再选）。合计六科，满分 150×3 + 100×3 = **750**。

---

## 0. 先确认的边界约定（实现契约）

| 编号 | 问题 | 结论 | 实现位置 |
|---|---|---|---|
| ① | 不完整考试中已录入的单科成绩是否参与该科平均分？ | **是**。单科平均遍历全部考试，逐科取有效分数累加，与考试是否完整无关。 | `stats.subjectStats()` |
| ② | 不完整考试是否参与总分平均？ | **否**。只有六科齐全的考试才累加出总分，才进入总分平均样本。 | `stats.isComplete()` / `stats.totalStats()` |
| ③ | 雷达图默认展示什么？ | 默认 **最近一次完整考试**，可切换为「指定某次考试」或「六科平均分」；可叠加平均值作对照。 | 图表视图 · 雷达卡片 |
| ④ | 折线图中某次考试缺某科时如何处理？ | **断线**，不用 0 填充。缺考点的相邻两点不连线，孤立点画成空心标记。 | `charts.buildSegments()` |
| ⑤ | 院校层次参考基于哪个分数？ | 默认 **总分平均值**，可切换为 **最近一次完整考试总分**。 | `tiers.matchTier()` |

**"完整考试"的定义**：以**当前选科组合的六科**为准，六科全部有合法分数。切换选科后，完整性判定会随之重算（这是符合预期的——原来的完整考试在新组合下可能变成缺科）。

## 1. 数据结构

### 1.1 整体状态对象

持久化到 `localStorage['hs-grade-report-v1']`，导出/导入使用同一份结构。

```jsonc
{
  "version": 1,
  "config": {
    "primary": "physics",                      // 首选科目："physics" | "history"
    "secondary": ["chemistry", "biology"],     // 再选 2 科（无序，渲染时按固定顺序排列）
    "fullMarks": {},                           // 可选覆盖：{ "math": 150 } 不填则用默认满分
    "tiers": [ /* 见 1.4 院校层次区间 */ ],
    "theme": "auto"                            // "auto" | "light" | "dark"
  },
  "exams": [ /* 见 1.2 考试记录 */ ]
}
```

### 1.2 考试记录 Exam

```jsonc
{
  "id": "e1x2y3z4",          // 本地生成，用于编辑/删除定位
  "name": "高二上期中考试",   // 必填
  "date": "2025-04-25",      // 必填，YYYY-MM-DD，用于时间排序
  "feeling": "数学发挥失常",  // 选填，文字备注
  "classRank": 12,           // 选填，正整数
  "gradeRank": 86,           // 选填，正整数
  "scores": {                // 仅存"已录入"的科目；未录科目**不写 key**（不是 0）
    "chinese": 118,
    "math": 138,
    "foreign": 124,
    "physics": 90,
    "chemistry": 88,
    "biology": 92
  },
  "createdAt": 1714521600000
}
```

> **关键设计**：缺考用「key 不存在」表达，而不是 `0` 或 `null`。
> 这样 `0` 分（真实考了但得 0 分）与「没录入」在语义上完全区分，平均分、折线断点、完整性判定都不会被污染。

### 1.3 科目字典（静态常量）

| key | 名称 | 简称 | 默认满分 | 分组 |
|---|---|---|---|---|
| `chinese` | 语文 | 语 | 150 | required（必考） |
| `math` | 数学 | 数 | 150 | required |
| `foreign` | 外语 | 外 | 150 | required |
| `physics` | 物理 | 物 | 100 | primary（二选一） |
| `history` | 历史 | 史 | 100 | primary |
| `chemistry` | 化学 | 化 | 100 | secondary（四选二） |
| `biology` | 生物 | 生 | 100 | secondary |
| `politics` | 政治 | 政 | 100 | secondary |
| `geography` | 地理 | 地 | 100 | secondary |

**六科顺序（固定）**：语文 → 数学 → 外语 → 首选 → 再选（按 化/生/政/地 顺序）。
**满分合计**：150×3 + 100 + 100×2 = **750**。

### 1.4 院校层次区间 Tier

```jsonc
{
  "id": "t1",
  "name": "顶尖 985",
  "min": 660,                       // 含
  "max": 750,                       // 不含（最高一层取到上限本身）
  "color": "#FF375F",
  "note": "清华 675 / 北大 663 / 上交 660-"   // 参考锚点，仅作说明文字
}
```

默认区间（总分 **750** 制，参照江苏物理/历史类近年投档位次的**粗略**刻度，可完全自定义）：

| 层次 | 区间（含下界） | 参考锚点 |
|---|---|---|
| 顶尖 985 | 660 – 750 | 清华 675、北大 663、上交 660- |
| 中上 985 | 630 – 660 | 复旦 655、南大 640、浙大 639、东南 634- |
| 中游 985 / 顶尖 211 | 610 – 630 | 南航 614、苏大部分专业组 621–624- |
| 中上 211 / 强一本 | 580 – 610 | 江南大学 603、南邮 585、南师大热门组 602- |
| 普通一本 | 532 – 580 | 超过特殊类型招生控制线，涵盖省属重点及普通一本 |
| 二本 / 普通本科 | 484 – 532 | 达到本科线附近 |
| 本科线以下 | 0 – 484 | 尚未达到本科线，优先补弱科 |

匹配算法：把区间按 `min` **降序**排序，取**第一个** `score >= min` 的区间。该写法对区间之间存在缝隙或相互重叠都是健壮的（重叠时自动取更高的一档）。

> **改区间的位置**：应用内「设置 → 院校层次参考区间」，可增删改每一档的名称与上下界；改完立即重算，无需改代码。
> 各省批次线差异极大（同样的总分在不同省份可能差出两个层次），因此默认值只当作"标尺示例"，请按本省实际投档情况自行校准。

> **声明（界面内也会常驻显示）**：层次参考只由"总分落在哪个区间"机械映射得出，**不考虑**省份、年份、选科组合、专业热度、招生计划增减、投档规则、单科成绩要求、体检与政审等大量决定性因素，仅用于给自己一个粗略的定位感，不能作为志愿填报依据。

### 1.5 无需持久化的派生数据

全部由纯函数从 `config + exams` 实时算出，不落盘，避免数据不一致：

- `subjectKeys`（当前六科 key 数组）
- `subjectStats`（每科：平均/最高/最低/次数/明细）
- `totalStats`（完整考试的总分序列、平均、最高、最低、最近一次）
- `tierResult`（层次匹配结果 + 距下一层次差多少分）

### 2.1 六个视图职责

| 视图 | 内容 |
|---|---|
| **概览** | 院校层次参考大卡（含区间色带 + 分位标记）、四张指标卡（总分平均 / 最近完整总分 / 考试次数 / 完整考试数）、六科平均横向条形 |
| **录入** | 考试信息表单（名称/日期/感觉/班排/年排）+ 六科分数输入，实时显示"已录 N/6 科"与总分（未满六科明确提示"本次不计入总分统计"）；支持编辑与删除 |
| **成绩** | 双 Tab：**按考试**（卡片列出每次考试六科明细、总分或"未录满"标记）／**按科目**（选一科，列出历次成绩、得分率、与平均差） |
| **图表** | 雷达图卡（数据源可切换 + 平均值对照开关 + 六科图例）／折线趋势卡（科目 chip 筛选 + 纵轴原始分/得分率切换 + 悬停查看当次全部科目） |
| **统计** | 单科平均表（含样本数，标注"含不完整考试的已录科目"）、总分平均表（仅完整考试）、院校层次参考与计算说明 |
| **设置** | 选科设置（改选科弹窗提示影响）、满分自定义、院校层次区间编辑器（增删改 + 一键恢复默认）、数据管理（导出/导入/清空） |

### 2.2 选科修改的影响提示

弹窗明确列出三条后果后再执行：

1. 不在新组合中的科目成绩将被**隐藏并停止参与统计**（底层数据保留，切回即恢复）；
2. 部分考试可能因缺科而**不再计入总分平均**；
3. 六科平均分与雷达图形状会随之变化。

若尚无任何考试数据，则静默应用，不打扰用户。

### 2.3 输入校验规则

- 分数：必须为数字、`0 <= v <= 该科满分`，允许 0.5 分步进；留空表示"未录入"。
- 至少录入 1 科才允许保存。
- 班级/年级排名：选填，须为正整数。
- 日期：须合法；排序按 `date` 升序，同日按 `createdAt` 升序。
- 失焦即校验并给出红色描边 + 行内提示，不弹 alert。

## 3. 图表实现要点

### 3.1 雷达图（`drawRadar`）

- **归一化**：语数外满分 150、其余 100，若直接混画会把 100 分制科目压扁。故**半径 = 得分率 = 分数 / 满分**，轴标签同时显示 `语文 118/150 · 78.7%`，兼顾公平与可读。
- 网格：5 圈正六边形 + 6 条辐条 + 外圈轴标签。
- 数据源：`最近一次完整考试` / `指定考试` / `六科平均`；勾选对照后叠加灰色平均值多边形。
- 动画：整体 `progress 0→1` 驱动多边形半径生长；数据点按轴序**错峰弹出**（`t = 0.35 + i * 0.07`），配合 `easeOutBack` 回弹。

### 3.2 趋势折线图（`drawLines`）

- 横轴：按时间排序的考试序号；标签为 `M/D`，考试数 > 6 时倾斜 -35° 绘制。
- 纵轴：`原始分`（0 – 150 固定，便于横向比较）或 `得分率`（0 – 100%）；仅勾选单科且该科满分为 100 时，自动贴合该科满分。
- **断点处理**：`buildSegments()` 把每科的点序列按"连续非空"切成若干段，段与段之间不连线；孤立单点画成空心圆。**绝不补 0**。
- 动画：按路径弧长比例渐进描线（`strokeProgressive`），先画网格与坐标轴（0–0.18），再逐科错峰绘线并弹出数据点。
- 悬停：命中最近的 x 序号，画竖直参考线与高亮点，浮动面板列出当次**所有已显示科目**的分数；缺考科目显示"未录入"。

### 3.3 动画驱动

```js
animate(duration, onFrame) // requestAnimationFrame + easeOutCubic / easeOutBack
```

每个图表持有 `token`，切换数据时自增 token 使旧动画帧自动失效，避免多段动画互相打架。
Canvas 按 `devicePixelRatio` 缩放，保证 Retina 屏不糊；`ResizeObserver` 监听容器尺寸变化后重绘。

## 4. 界面设计规范（Apple 风格）

### 4.1 视觉令牌

```css
--radius-xl: 28px;  --radius-lg: 22px;  --radius-md: 16px;  --radius-sm: 11px;
--accent: #0A84FF;  --accent-2: #5E5CE6;   /* 蓝紫主色，深色模式提亮 */
--ease-soft:   cubic-bezier(0.32, 0.72, 0, 1);      /* Apple 标志性缓出 */
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);   /* 回弹 */
```

### 4.2 液态玻璃（Liquid Glass）

```css
.glass {
  background: color-mix(in srgb, var(--card) 72%, transparent);
  backdrop-filter: blur(30px) saturate(190%);
  border: 1px solid var(--card-border);          /* 细边框高光 */
  box-shadow: var(--shadow), inset 0 1px 0 rgba(255,255,255,.6); /* 顶部内高光 */
}
```

应用于：顶部导航栏、所有卡片、弹窗、Toast、悬浮提示。
背景铺一层柔和的径向渐变光斑，让毛玻璃有内容可"透"，玻璃质感才成立。

### 4.3 动效清单

| 场景 | 动效 |
|---|---|
| 视图切换 | `fade + translateY(16px) + scale(.985)`，460ms `--ease-soft`，卡片按序 stagger 入场 |
| 卡片悬停 | `translateY(-3px)` + 阴影加深，340ms |
| 按钮按下 | `scale(.96)`，120ms；hover `scale(1.02)` |
| 输入框聚焦 | 外发光 `ring` 扩散 + 边框变主色 |
| Tab 切换 | 选中胶囊**滑动**到目标位置（`transform` 过渡），非瞬间跳变 |
| 弹窗 | 背景 `blur` 渐显 + 面板 `scale(.92)→1` spring 回弹 |
| Toast | 底部上滑 + 淡出，自动 2.6s 消失 |
| 图表 | 雷达生长 / 折线渐进描线 / 数据点错峰弹出 |

### 4.4 响应式

- 断点：`<= 900px` 单列布局、导航降级为可横向滚动的胶囊条；`<= 560px` 缩小内边距与字号、图表高度下调。
- 网格：桌面 `repeat(auto-fit, minmax(220px, 1fr))`，天然自适应。
- 深色模式：跟随系统 `prefers-color-scheme`，并支持手动切换（存 `config.theme`）；图表颜色从 CSS 变量实时读取，随主题重绘。

## 5. 技术选型说明

| 需求 | 方案 | 理由 |
|---|---|---|
| 无需服务器 | 单个 `.html` 文件，双击 `file://` 打开 | ES Module 在 `file://` 下会被 CORS 拦截，因此全部代码内联、使用经典脚本作用域，零 `fetch`、零 CDN |
| 数据持久化 | `localStorage` + JSON 导出/导入 | 免安装。若浏览器禁用本地存储（隐私模式等），自动降级为内存态并顶部提示"请及时导出备份" |
| 图表库 | **自研 Canvas 引擎**（约 300 行） | 需求要求"不依赖外部服务器"，而 CDN 图表库离线不可用、本地引入又破坏单文件分发。自研可获得与 Apple 风格一致的缓动与弹跳动画控制权，且体积仅几 KB |

> 若日后希望换成 ECharts：`charts.js` 中的 `drawRadar` / `drawLines` 是仅有的两个绘制入口，替换这两个函数即可，其余统计与 UI 逻辑不受影响。

## 7. 使用步骤

1. **双击 `index.html`**（Chrome / Edge / Firefox 均可，无需安装任何东西）。
2. 首次打开先去「**设置**」把选科改成自己的组合（首选二选一 + 再选四选二），并按本省情况调一下「院校层次参考区间」。
3. 到「**录入**」填考试名称、日期、整体感觉、班级/年级排名，再逐个填六科分数 → 「保存考试」。
   - 分数框留空 = 该科缺考；超过满分会立刻标红并给出提示。
   - 顶部实时显示「已录 N/6 科」，六科齐全才显示总分。
4. 「**概览**」看总分平均、层次参考、雷达图、单科平均与趋势。
5. 「**成绩**」按考试或按科目两种视角翻看明细。
6. 「**图表**」切换雷达图数据源（最近完整考试 / 指定考试 / 六科平均，可叠加平均对照）与折线图科目筛选、纵轴口径（原始分 / 得分率）。
7. 「**统计**」核对单科平均、总分平均的样本数，并阅读统计口径说明。
8. 换电脑或清浏览器缓存前，务必到「设置 → 导出备份 JSON」把数据存成文件。

> 数据存在浏览器 `localStorage`（键名 `hs-grade-report-v1`）。同一台电脑、同一个浏览器、同一个文件路径下打开，数据就还在。
> 若用隐私模式打开或浏览器禁用了本地存储，页面顶部会出现橙色警告条——此时数据只在内存里，请立即导出备份。

## 8. 边界情况自检清单（实现后逐条对照）

| # | 检查项 | 期望表现 | 代码位置 |
|---|---|---|---|
